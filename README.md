# 💼 Professional Resume Website

A personal resume website built with HTML5 and CSS3 as part of my Software Development programme at CodeSpace Academy.

The project focuses on translating a Figma design into a structured web interface while applying semantic HTML, CSS styling, layout techniques, and responsive design principles.

## 🎨 Design Reference

The website was developed with reference to the CodeSpace Academy Figma design.

[**View the Figma Design**](https://www.figma.com/design/fM2tutgIH0k1SrNir4MVe3/SDF-Resume-Project-STUDENT-REFERENCE-FILE?node-id=0-1&t=yGSXI1yv4AgjKBvA-1)

## ✨ Project Features

The project brief covers the following sections:

* Profile and summary
* Proficiency bars
* Skills tags
* Projects grid
* Education and work history
* Tools section
* Contact footer

The implementation focuses on semantic HTML, structured content, CSS layout and styling, and responsiveness across screen sizes.

## 🛠️ Technologies

* HTML5
* CSS3
* Git
* GitHub
* Figma (design reference)

## 🧠 What I Learned

Through this project, I practised translating a visual design into a web interface, structuring content with semantic HTML, and using CSS to control layout, spacing, typography, and responsive behaviour.

The project also reinforced the importance of readable code, accessibility, and version control in front-end development.

## 🎯 Project Purpose

This project demonstrates my foundational front-end development skills and my ability to work from a design reference to build a professional web page.
